# 🌌 AakashPlay — Official App & Software Store

A modern, high-performance web platform inspired by the **Google Play Store & Apple App Store**, built with **3D Clay UI (Claymorphism)** and powered live by **Firebase Realtime Database**.

---

## 🌟 Highlights

- **⚡ Live Firebase Realtime Database Sync**: Automatically synchronizes and renders Android APKs, Web Apps, and Open-Source libraries.
- **📱 Play Store Aesthetics**: 3D clay cards, spotlight carousel, leaderboard top charts, and responsive mobile sandbox preview.
- **🎨 Cosmic Purple & Neon Violet Theme**: Sleek clay light & dark mode with crisp micro-interactions.
- **📲 Instant Phone QR Installer**: Camera scan QR code to download and install Android APKs directly on mobile.
- **🌐 Interactive Live Web Sandbox**: Preview live web SaaS apps in isolated mobile, tablet, and desktop viewports.
- **🔒 Privacy First & 100% Real Metrics**: Zero mock data, verified developer badge, and direct links to GitHub repositories and APK assets.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (3D Claymorphism & Micro-Animations)
- **Backend & Database**: [Google Firebase Realtime Database](https://firebase.google.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Vector SVGs
- **Deployment**: [Netlify](https://www.netlify.com/) via [GitHub Actions CI/CD](https://github.com/features/actions)

---

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/aakashsakhalkar/AakashPlay.git
cd AakashPlay

# 2. Install dependencies
npm install

# 3. Create .env file with your Firebase Database URL
# VITE_FIREBASE_DB_URL=https://your-firebase-database.firebaseio.com/CareerHighlights/projects.json

# 4. Start local development server
npm run dev
```
